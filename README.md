# УчПлатформа — учебная платформа на React

Лабораторные работы №3–4 по дисциплине РПИ.
В лабораторной №4 одностраничный лендинг переделан в приложение с маршрутизацией (React Router).

Учебная платформа соединяет компании, образовательные учреждения и НКО
с профессиональными лекторами, спикерами и тренерами.

##  Запуск проекта

```bash
npm install
npm start
```

Открой [http://localhost:3000](http://localhost:3000) в браузере.

##  Стек

- **React 19** (Create React App)
- **React Router** (`react-router-dom`) — маршрутизация
- **React Hooks**: useState, useDeferredValue, useMemo, useParams, useNavigate
- **CSS3** — без UI-фреймворков
- **Google Fonts**: Inter, Playfair Display

##  Страницы

| Адрес | Страница | Компонент | Содержимое |
|---|---|---|---|
| `/` | Главная | `HomePage` | Hero, блок лекторов, О нас, Партнёры, превью лекторов |
| `/lecturers` | Лекторы | `LecturersPage` | Сетка 10 лекторов + поиск по ФИО + фильтр по полу |
| `/lecturers/:id` | Карточка лектора | `LecturerDetailPage` | Дисциплины (аккордеоны), тарифы, запись, «Назад к списку» |
| `/about` | О нас | `AboutPage` | Преимущества (01/02/03), миссия |
| `/partners` | Партнёры | `PartnersPage` | ICL, Татнефть (кликабельные ссылки) |
| `*` | 404 | `NotFound` | Страница «не найдено» для любого другого адреса |

Меню (`Header`) и футер вынесены в общий компонент `Layout`, страницы
выводятся в его `<Outlet />`, поэтому меню видно на всех страницах.

##  Функциональность

- Маршрутизация через `react-router-dom`: `<BrowserRouter>`, `<Routes>`, `<NavLink>`
- Динамический маршрут `/lecturers/:id`: лектор ищется по `useParams()`
- Кнопка «Назад к списку» через `useNavigate()`
- Плавный поиск по ФИО через `useDeferredValue` (вклад Зарины, PR #1)
- Модальные окна:
  - **«Оставить заявку»** — в хедере
  - **«Записаться на занятие»** — на странице лектора
- Валидация форм: имя, телефон, email, дисциплина/тариф
- Аккордеоны дисциплин (10 тем на дисциплину)
- Адаптивная вёрстка (десктоп / планшет / мобильный)

##  Дизайн
